# Gemini

Follow root `AGENTS.md`. Architecture: `docs/architecture.md`. Locked decisions: `docs/adr/`.

Browser session = NextAuth in `apps/web`. UI = Mantine, no inline styles. OTP stays in `apps/api`. Next.js does not use Prisma or the Siray SDK. Action payloads are JSON body only, never query params (ADR 0016). Web architecture follows ADR 0017 (pages in `app/`, domain presentation in `views/<page>/components/`, generic UI only in `components/`, and explicit API routing in `lib/api-mapping.ts`). All list queries must use server-side pagination, sorting, and filtering via database layer (ADR 0018). Next.js frontend MUST NOT perform periodic interval-based API polling/refetching (`refetchInterval` / `setInterval` API fetch); realtime sync must be strictly event-driven via SSE (`/api/invoices/events`) and query cache invalidations. Postman updates strictly maintain 1 collection file (`ai-gen-free.postman_collection.json`) and 1 environment file (`local.postman_environment.json`). Public browser-facing endpoints MUST NOT expose upstream AI model names or provider IDs (only abstract opaque capability IDs such as `t2i-standard`, `video-standard`, etc.). Every model/provider integration in `packages/providers-*` MUST adapt its specific aspect ratio/image size payload referencing canonical mappings in `apps/web/lib/aspect-ratio.ts` without falling back to 1024x1024 for non-square ratios. Direct developer/agent test probes to upstream providers MUST use standardized prompt prefix `[TEST:DEV]` or `[TEST:QA]`.
