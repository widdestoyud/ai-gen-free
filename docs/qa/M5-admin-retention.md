## Catatan fail-closed

- Index mutex **hanya** di SQL migrasi. Jangan hapus `job_one_active_per_user`.
- Gerbang cooldown submit = **`users.nextGenerateAt`**. `Job.nextGenerateAt` hanya snapshot sukses. UI generate/job memakai `GET /jobs` / `GET /me`, bukan `max(jobs.nextGenerateAt)`.
- `PUT generate_cooldown_seconds` **dilarang** menyentuh `User.nextGenerateAt`. Reset = `POST` terpisah per user (ADR 0004).
- Sweep hanya `outputs/` dan `inputs/`. Jangan pasang lifecycle S3/MinIO bucket-wide 14 hari (bukti `proofs/**` ikut hilang).
- Setelah `purgedAt`, status job tetap `succeeded`; capture tidak di-refund.
- Signed URL TTL 600 detik ≠ retensi 14 hari (`availableUntil` = `JobAsset.expiresAt`).
- S3 `signGetUrl` tidak `HEAD` objek; setelah sweep, `purgedAt` mencegah sign. Objek hilang sebelum `purgedAt`: adapter memory melempar → `url: null`; MinIO signed tetap bisa terbit sampai sweep (bukan 500).
- Live Compose (race HTTP, signed MinIO, Basic+OTP admin) belum dieksekusi. Ulangi alur admin + retensi setelah `docker compose up --build` jika gerbang manusia mensyaratkan bukti Compose.
- Merge **tidak** diblokir: tidak ada kasus wajib **fail**.
